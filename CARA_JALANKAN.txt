🚀 CARA TERMUDAH (REKOMENDASI):

1. Buka Command Prompt (Win+R, ketik "cmd", Enter)
   
2. Masuk ke folder Laravel:
   cd "D:\05. SEM5\PB_Kerangka Kerja\laravel_api_25"

3. Jalankan file setup:
   setup.bat
   
   File ini akan otomatis melakukan semua setup dan menjalankan server!

4. Buka browser:
   http://localhost:8000

==========================================
CARA MANUAL (Jika setup.bat tidak berfungsi):
==========================================

1. cd "D:\05. SEM5\PB_Kerangka Kerja\laravel_api_25"
2. composer install
3. php artisan key:generate
4. php artisan migrate
5. php artisan serve

Untuk detail lengkap, lihat: README_SETUP.md
